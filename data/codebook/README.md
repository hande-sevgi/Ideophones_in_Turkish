# Data codebook

This directory documents the datasets and variables used in the Chapter 4 analysis workflow.

## Contents

- `files.csv` describes each source and processed data file.
- `variables.csv` defines the variables used in the processed datasets.

## Experimental structure

Experiments I and II contain three target adverbial types:

- manner;
- temporal;
- ideophone.

Their complete design is 3 × 2 × 2:

- target adverbial type: manner, temporal, or ideophone;
- continuation type: matching or mismatching;
- position of negation: first or second clause.

The primary analyses compare manner and temporal adverbials using a 2 × 2 × 2 design. The extended analyses include ideophones and use the complete 3 × 2 × 2 design.

Experiment III examines ideophonic and non-ideophonic adverbials in affirmative and negative single-clause sentences. It also compares different degrees of morphological integration.

## Data-processing principles

Files in `data/input/` are treated as immutable source data.

All participant exclusions, variable recoding, factor-level standardization, missing-value handling, and dataset transformations are implemented in `code/scripts/02_prepare_processed_data.R`.

Files in `data/processed/` are generated by the preparation script and should not be edited manually.
